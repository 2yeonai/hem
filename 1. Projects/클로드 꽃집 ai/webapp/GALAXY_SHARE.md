# 갤럭시 통화 공유 프로토타입 — 2026-11-16

기준: PR #2 최신 c6ba568 (2단계 코드 6d278a7 + 진행기록 갱신).
번호·통신사·기본 전화 앱은 변경하지 않는다. 현재 010 번호의 통화 종료 후 삼성 앱의 공유 기능을 사용한다.
이번 구현은 설치형 웹앱(PWA) 공유 수신이며 Android APK나 통화감지 서비스가 아니다.

## 실제 구현

- galaxy.py: 설치용 manifest, 서비스워커 제공, 로그인·권한 보호된 공유 확인 화면.
- static/galaxy/: 공유 POST를 서버 전송 전에 서비스워커가 수신하고 IndexedDB에 보관. 전사문 text/plain 파일과 일반 텍스트, 녹음 파일 수신. 로그인 후 확인 버튼으로 기존 /intakes 접수로 보낸다.
- 공유 자료는 UI에 textContent/value로 표시한다. 세션/CSRF 토큰을 임시 자료 저장소에 저장하지 않는다. 기존 서버 CSRF/권한 검사를 우회하는 업로드 API를 만들지 않았다.
- 녹음과 전사문을 함께 받으면 기본은 녹음 분석. '전사문만 보내기'를 선택하면 별도 음성인식 호출을 생략한다. 접수 성공 시 기기 임시 자료 삭제, 실패 시 재전송 가능. 수동 삭제 버튼 제공.
- 임시 자료 1건만 보관하고 새 공유가 오면 교체한다. 24시간 초과 자료는 다음 화면 로딩 때 삭제한다. 백그라운드 자동 삭제를 보장하지 않는다. 개인 휴대전화 사용을 전제로 하며 브라우저 데이터 삭제도 자료를 제거한다.
- 파일 합계 24MB, 파일 최대 2개(녹음 1개+전사 1개), 텍스트 10만자. 파일 MIME/확장자 검사는 수신 형식 제한이며 실제 오디오 내용 검증은 아니다.
- 웹앱 준비 전 공유 요청이 서버에 직접 오면 자동 저장하지 않는다. 정상 서비스워커가 없거나 로그인 만료 시 다시 준비/로그인이 필요하다.

## 설치·사용 (승인 후 HTTPS 시험 환경 필요)

1. 갤럭시 Chrome에서 시험 사이트를 열고 로그인한다. 목록의 '통화 공유 접수'로 이동한다.
2. Chrome 메뉴에서 '앱 설치'를 선택한다. 일반 바로가기만 추가하는 것과 구분한다. '공유 준비 완료'를 확인한다.
3. 가상 통화를 녹음하거나 가상 음성 파일을 준비한다. 삼성 전화의 녹음 목록/음성녹음에서 파일 또는 전사문을 선택 → 공유 → '꽃집 전달'.
4. 공유 확인 화면에서 내용을 보고 'AI 접수'를 누른다. 앱이 직접 파일 경로를 탐색하지 않는다.
5. 접수 기록에서 AI 결과 또는 오류/재시도·수동 접수를 확인한다.

현재 운영 배포를 하지 않았으므로 실제 휴대전화 설치 URL을 새로 제공하지 않았다.
공유 대상 표시는 Chrome 설치·HTTPS·서비스워커 준비 및 기기 지원에 의존한다. 삼성 인터넷 지원을 확인한 것으로 간주하지 않는다.

Android TelephonyCallback의 통화 상태 감지는 READ_PHONE_STATE 권한이 있는 보조 앱으로 검토할 수 있다.
그러나 상태 감지는 녹음 파일·음성 데이터 접근 권한을 주지 않는다. 이번 공유 방식에는 보조 앱이 필수는 아니다.
추후 알림으로 공유를 안내하는 보조 앱은 별도 가치가 있지만 백그라운드 제약·권한·멀티 SIM·기기별 검증이 필요하다.
실시간 대안은 통화 중 사람이 간단히 메모하거나 통화 종료 후 전사문을 전달하는 것.
전화사업자/VoIP 서버에서 음성을 받는 방식은 번호 유지·착신 경로·고지·요금 검토가 필요하므로 이번에 연결하지 않았다.

## Playwright 로그인 실패 해결 및 종단 통과 — 2026-11-16

이전 timeout은 waitForURL 패턴이나 계정 오류가 아니라 headless-shell에 강제 적용한
`--single-process` 실행 모드에서 로그인 버튼 이후 POST/탐색이 진행되지 않던 문제로 재현했다.
해당 옵션을 제거해 다중 프로세스로 실행하자 POST /login 302, Location /, GET / 200으로 정상 진행했다.
앱의 보안 정책은 완화하지 않았다. 로컬 APP_ENV=development에서 Secure=false, HttpOnly=true 쿠키를 확인했다.
